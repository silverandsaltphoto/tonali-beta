# Tonali beta

Tonali learns how you edit from your own finished Lightroom Classic work, then edits new weddings the same way. Everything runs on your computer: your photos, catalogs and recipes never leave it.

This page holds the free beta builds for testers. Thanks for trying it.

## Install

1. Open the newest release on the **Releases** page (right side of this page).
2. Download the file for your computer:
   - **Mac (Apple silicon):** the `.dmg` file. Open it and drag Tonali to Applications.
   - **Windows:** the `.exe` file. Windows may say "Windows protected your PC" because the beta isn't signed for Windows yet. Choose **More info › Run anyway**.
3. Open Tonali and follow the setup.

## Updates

Tonali checks this page for new beta versions while it's open, downloads them in the background, and installs them the next time you quit. Those update checks are the only thing Tonali sends over the internet.
